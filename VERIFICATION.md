# Проверка NoteSound 2.0 — 28 октября 2026

Проверена локальная версия. Этот документ не подтверждает публикацию обновления на GitHub Pages или запуск внешнего API.

## Автоматические проверки

- `pnpm test`: **324 теста, 22 файла — успешно**.
- `pnpm typecheck`: успешно.
- `pnpm lint`: успешно.
- `pnpm build`: успешно; основной JS около 561 КБ до сжатия, около 176 КБ gzip.
- `pnpm check:preview`: успешно — оболочка и 14 ресурсов доступны по пути `/NoteSound/`, правильные типы JS/CSS.
- Service Worker содержит 19 ресурсов оболочки. Музыка не кэшируется без действия пользователя.

Покрыты документированный ответ Hitmoz, нормализация и удаление неподтверждённых аудиоссылок, отдельное разрешение воспроизведения, реестр лицензий, CORS, SSRF/DNS-защита, ограничения запросов, проверка Telegram initData и подписанная сессия каталога. `sendAudio` проверен с подставным ответом Bot API; реальных сообщений не отправляли.

Покрыты веса вкусов, 70% фактического прослушивания, мягкие ограничения повторов, небольшой/пустой каталог, ручной приоритет, заполнение семи мест и пополнение ниже трёх. Проверены миграции, перенос прежней библиотеки, разделение локальных Telegram-профилей, настройки и сохранение cue points.

Аудиопроверки включают два канала, кривые усиления, временные метки, середину перехода без повторной загрузки, Pause/Resume, замену следующей песни, поздний запуск после отмены, отказ Web Audio с возвратом к обычному звуку, смену громкости, отмену устаревших операций и отсутствие фиктивного зачёта перемотки как прослушивания.

## Проверено в браузере

Встроенный браузер, локальный адрес `http://127.0.0.1:5173/`, мобильный размер **390 × 844**:

- Поиск по `electronic` возвращает собственные записи NoteSound.
- Ручной запуск песни включает Smart Wave; очередь содержит семь следующих композиций с понятными причинами выбора.
- Плеер показывает обложку, название, исполнителя, реальную позицию и музыкальные элементы управления.
- Во время Wave Mix появилась вторая обложка с изменяемой прозрачностью; после перехода название изменилось на «Стеклянный сад», позиция продолжилась с авторской cue-метки. Дальнейшие песни переключались автоматически.
- Пауза останавливает тестовое воспроизведение. Перезагрузка восстанавливает трек/позицию без автозапуска.
- Сохранены [плеер](docs/notesound-2-player-mobile.png) и [очередь](docs/notesound-2-queue-mobile.png). Мобильный размер после проверки сброшен.

Локальный backend запущен отдельно. `/api/catalog/status` ответил HTTP 200: оба флага Hitmoz выключены, лицензированный реестр пуст. Поиск отключённого Hitmoz вернул пустой результат и объяснение; сторонние MP3 не загружались.

## Что пока не проверено

- Фоновая работа на физических iPhone/Android внутри Telegram, при блокировке экрана, звонках и выгрузке WebView.
- Доступность Hitmoz в боевой инфраструктуре и право использования его каталога. Ранее исследованные адреса возвращали HTTP 403.
- Реальное сведение стороннего лицензированного каталога: пока не предоставлены разрешённый URL, CORS и подтверждение прав.
- Docker-образ, внешний хостинг backend, реальные Telegram initData в продакшене и отправка лицензированного файла в чат.
- Обновление публичного сайта: версия 2.0 подготовлена локально и в архиве, автоматически не публиковалась.

Автотесты моделируют браузерные и сетевые события. Они не заменяют проверку ограничений iOS/Telegram и условий конкретного музыкального источника.
