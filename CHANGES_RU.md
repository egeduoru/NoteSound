# Изменения NoteSoundbot 2.0

Модернизирован существующий React/TypeScript-проект. Сохранены Liquid Glass, бот, Pages-путь, библиотека, плейлисты, избранное и аудиоимпорт. До переработки создан архив отката с контрольной суммой.

## Плеер

- Основной HTML5 Audio с квадратной обложкой вместо YouTube.
- Две переиспользуемые деки для независимого опционального Mix, единый транспорт, отмена гонок, корректные Pause/смена песни.
- Media Session, прогресс, системные команды и безопасная подсказка audioSession при поддержке.
- Официальный YouTube оставлен под выключенным флагом отката; извлечения/скрытого iframe нет.

## Каталоги

- HitmozProvider/LicensedAudioProvider, модель прав, нормализация JSON, раздельные метаданные и разрешение аудио.
- Node API: канонический реестр, кеш, таймауты, параллельность, rate limiting, проверка URL/DNS/SSRF.
- Подписанный Telegram initData и ограниченный сеанс каталога для долгого слушания, BOT_TOKEN только на сервере.
- Hitmoz выключен: исходные домены вернули 403, права/доступ не подтверждены, download не используется автоматически.
- Подготовлена выключенная самостоятельная sendLicensedAudio с отдельным правом доставки; маршрута/кнопки пока нет.

## Волна и Mix

- Smart Wave запускается после выбора аудио, целевые доли 40/30/20/10, реальные сигналы, взвешенный случайный выбор.
- Семь следующих записей, пополнение ниже трёх, ручная очередь приоритетна; Previous из фактической последовательности.
- Дубликаты/дизлайки, мягкая история 30 дней и разнообразие исполнителей.
- Wave Mix выключен по умолчанию: Web Audio equal-power fade 2–12 секунд, достоверные Cue In/Out, без меток начало 0:00.
- Собственные короткие записи размечены по авторской тактовой сетке, не по распознанным припевам.

## Данные и выпуск

- Dexie v4: сигналы, таблица меток и тип очереди без удаления прежней библиотеки.
- Локальная изоляция Telegram-профилей и копирование старой базы в первый назначенный профиль без удаления исходника.
- Сохранение/восстановление музыкальных меток при подготовке и запуске треков.
- Настройки открытий/Mix, сброс предпочтений, лайки/дизлайки и причины рекомендаций.
- Обновлены workflow Pages, адрес отдельного API, тесты и документация. Числа проверок — VERIFICATION.md; физические устройства, внешний Hitmoz playback и публикация API отдельно не заявлены.
