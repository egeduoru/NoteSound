# NoteSoundbot 2.0

Музыкальный Telegram Mini App существующего бота **@NoteSoundbot**. Выбор доступной песни запускает аудио с обложкой и автоматически готовит Умную Волну. Независимая настройка Wave Mix добавляет плавные переходы между совместимыми записями.

Версия 2.0 подготовлена локально. Публичный сайт обновится после загрузки исходников и успешного GitHub Actions. Бот и адрес сохраняются: `https://egeduoru.github.io/NoteSound/`.

Для актуального комплекта используйте [пошаговую инструкцию Mini App](MINI_APP_RELEASE.md):
GitHub Pages — интерфейс, существующий Render — музыкальный API.
Публичный `config.js` позволяет изменить адрес API без пересборки готового сайта.

## Что доступно сразу

- Восемь собственных CC0-инструменталов NoteSound по 48 секунд; лицензия в `public/audio/LICENSE.txt`.
- Импорт личного аудио, библиотека, избранное, плейлисты, история и сохранение сеанса.
- HTML5 Audio, обложки, Play/Pause, Seek, Next/Previous и поддерживаемые системные команды Media Session.
- Smart Wave: автоматический подбор, приоритет ручной очереди, до семи следующих записей, лайки и дизлайки.
- Wave Mix: 2–12 секунд, две аудиодорожки во время перехода, достоверные музыкальные метки и запасной старт с начала.

Основной внешний поиск использует публичный каталог LightAudio через отдельный сервер.
Похожие исполнители подбираются также по метаданным Deezer; короткие фрагменты
Deezer не заменяют полные записи в Волне. Доступность конкретных песен зависит
от источника. Hitmoz по умолчанию выключен. Ненайденная песня не подменяется
демонстрационной записью. Поиск, обложки и запуск трека имеют отдельные бюджеты
запросов; ограничение 429 показывает время ожидания.

## Запуск

Требуются Node.js 24 и pnpm 11.25.0, как в workflow проекта.

На Windows после установки зависимостей дважды щёлкните **Start NoteSound.cmd** в папке проекта. Он запускает приложение и поиск музыки вместе, открывает страницу и сохраняет журналы в `.local/logs`. Повторный запуск использует уже работающие сервисы. После перезагрузки компьютера запустите этот файл снова.

Из терминала оба сервиса можно запустить командой `node scripts/start-local.mjs`.

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

При отдельном запуске через `pnpm dev` для внешнего поиска также запустите `pnpm dev:catalog` во втором терминале.

Откройте адрес Vite, обычно `http://127.0.0.1:5173/`. Для собственного каталога внешний сервер и ключ YouTube не нужны.

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm preview
```

Для API каталогов скопируйте `server/.env.example` в `server/.env`, затем из корня запустите:

```powershell
node --env-file=server/.env server/index.mjs
```

`pnpm server` использует уже заданные переменные процесса и сам `.env` не читает. Для связи frontend с локальным API создайте `.env.local` с `VITE_MUSIC_API_URL=http://127.0.0.1:3001` и перезапустите Vite. Пустой API без разрешённых записей не добавит песни.
