# Ограничения NoteSound 2.0

1. **Внешний каталог ещё требует подключения.** Работают собственные CC0-записи и личный импорт. Лицензированный реестр пуст; «ДИНАСТИЯ» и другие коммерческие треки во встроенном аудио не обещаются.
2. **Hitmoz выключен.** Контракт и Provider реализованы, исходные сайты при проверке вернули 403. Доступ, условия и права воспроизведения/сведения/распространения не подтверждены. Обхода и автоматического использования download нет.
3. **Pages не запускает сервер.** Для каталогов нужен отдельный HTTPS Node API, при необходимости разрешённый Parser API, реестр, хосты и Origin. Локальные изменения сами сайт не обновляют.
4. **Фон зависит от ОС.** Telegram/iOS/Android могут остановить WebView. Media Session/audioSession не гарантируют фон, блокировку и Mix при заморозке. Физические устройства не проверены.
5. **Mix не для любого файла.** Нужны права allowMix, доступное аудио, same-origin/blob или рабочий CORS. При отказе Web Audio/autoplay/следующего источника обычное воспроизведение сохраняет самостоятельность.
6. **Метки не угадываются.** Только достоверные manual/licensed_metadata/analysis; без них начало 0:00 и fade у конца. Собственные метки — авторская сетка тактов, не распознанные припевы. Нет автоматического анализа чужих песен, beat matching/time stretching.
7. **Подбор ограничен данными.** 40/30/20/10 — целевые доли. Маленький каталог ослабляет 30-дневное правило и разнообразие. Дизлайки/текущий трек/очередь исключаются; неизвестные жанры и BPM не выдумываются.
8. **Хранилище локальное.** Нет синхронизации устройств. Браузер и Telegram могут иметь разные базы, ОС может очистить данные. Сохраняются лимиты личного аудио и квота браузера. JSON не содержит аудиобайтов и доверенных разрешений.
9. **Сеансы конечны.** Для защищённого API нужен свежий подписанный initData; срок сеанса стандартно 8 часов. После истечения может понадобиться открыть Mini App заново. Локальное разделение ID не является серверной авторизацией.
10. **sendAudio — подготовленная функция.** Маршрута/кнопки пока нет, реальная отправка не проверена. Нужны отдельное право доставки и явный вызывающий код.
11. **YouTube — только откат.** По умолчанию выключен, в аудиоВолну/Mix не входит. При включении использует официальный API и видимое видео, зависит от квот/региона/встраивания, без извлечения аудио.
12. **Границы проверки.** Подставные сеть/AudioContext/Bot API проверяют код, не реальный музыкальный сайт или iPhone. Браузерные факты в VERIFICATION.md; Hitmoz playback, хостинг Node, Docker и физические устройства отдельно не заявлены проверенными.
