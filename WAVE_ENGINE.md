# Smart Wave и Wave Mix 2.0

Smart Wave выбирает следующую музыку. Wave Mix управляет переходом между выбранными записями. Автоподбор включён по умолчанию, Mix выключен; настройки независимы.

## Подбор и сигналы

Ручной выбор доступного аудио становится отправной точкой Волны. Новый выбор перестраивает подбор. Используются разрешённые записи, избранное, история, реальные метаданные и действия слушателя. Новый пользователь может начать с собственного/лицензированного топа и личной библиотеки. Провал конкретного запроса артиста не подменяется демо.

При стандартной интенсивности открытий 25% целевые доли: 40% похожего, 30% персонального, 20% нового, 10% популярного. Выбор взвешенный случайный, с перераспределением при нехватке групп; есть фиксируемый seededRandom для тестов. Причина similar/personal/discovery/popular сохраняется только при достоверном основании.

Похожесть использует исполнителя, полученные жанры и ответы адаптера; BPM/настроение не выдумываются. Популярность берётся из реального ранга/чарта. Интенсивность открытий меняет discovery; веса сигналов хранятся и нормализуются в настройках, отдельного UI-редактора всех весов нет.

| Сигнал | Вес |
|---|---:|
| Лайк | +5 |
| Избранное | +4 |
| Фактическое слушание не менее 70% длительности | +2 |
| Повторное воспроизведение знакомой записи | +2 |
| Ранний пропуск | −1 |
| Дизлайк | −8 и исключение автоматического подбора |

Запуск — факт старта, а не завершённое слушание. Положительное время растёт только при достоверном движении позиции во время play. Seek, пауза, замороженный WebView не начисляют время. Старой истории без таких данных не приписывается listen. Skip учитывается до max(10 секунд, 60% длительности).

## Повторы и очередь

Идентичность: ID, recording ID при наличии либо нормализованные название и исполнители. Служебные Official Audio/Lyrics/HD удаляются из сравнения, значимые Remix/Live/Acoustic сохраняются. Полной базы псевдонимов нет.

Текущий трек, дубликаты очереди и дизлайки — жёсткие исключения. Последние 30 дней — мягкий предел, последовательно ослабляемый при маленьком каталоге. Не больше двух записей исполнителя в пяти соседних применяется с учётом хвоста очереди, пока есть альтернативы. Ручной запуск знакомой или отклонённой записи остаётся явным действием пользователя.

Цель — семь следующих треков суммарно, включая ручные; пополнение при остатке меньше трёх. Ручные идут первыми и не теряются. Если их больше семи, автоматические временно не добавляются. Первоначальное заполнение добирает до цели даже при трёх восстановленных ручных треках.

Next берёт первый доступный элемент с приоритетом, ограничивает последовательные ошибки и обновляет подбор. Previous после нескольких секунд возвращает песню в начало, иначе берёт реально сыгранную предыдущую. Случайного предыдущего из результатов поиска нет.

За пополнение: максимум четыре операции метаданных, до четырнадцати проверок доступности по две одновременно. Повтор после ошибки расходует общий бюджет, устаревшие операции отменяются. Если разрешённых записей мало, очередь короче/исчерпана; бесконечного сканирования нет.

## Реальное сведение

WaveMixEngine: общий ленивый AudioContext, два MediaElementSource и GainNode. Исходящая дека затихает cosine, входящая появляется sine, предусмотрен запас −3 dB. Это Web Audio crossfade, не CSS-имитация; максимум два звучащих канала.

Длительность 2–12 секунд, стандарт 6. Есть умные метки и ранний переход. Требуются allowMix, рабочая подготовка следующего файла и same-origin/blob либо подтверждённый CORS. Отказ подготовки/autoplay/Web Audio сообщает о невозможности микса, обычное аудио сохраняет самостоятельность. Экономия трафика отключает подготовку.

Pause останавливает обе деки; Resume продолжает согласованный переход. Next/ручной выбор/seek отменяет устаревший Mix. Поздний play() не возрождает звук после паузы. Основная запись и Media Session меняются в середине; обложки следуют прогрессу. Incoming попадает в историю после реального старта без повторной записи на midpoint. Конец outgoing не вызывает дополнительный Next, ресурсы освобождаются.

## Музыкальные метки

Cue In/Out содержат уверенность и источник manual/licensed_metadata/analysis. Принимаются при уверенности от 0,7 и проверяются по длительности. Без пригодной метки старт 0:00. Если структура окончания неизвестна, fade у фактического конца, без произвольного отрезания 20–30 секунд. Автоматического распознавания припевов нет.

Восемь собственных 48-секундных инструменталов созданы scripts/generate-originals.py. Метки в catalog.ts размечены автором по тактам генератора: seconds = bar × 4 × 60 / BPM. Известные темпы — 80, 100, 72, 84, 112, 76, 104, 88 BPM. Эти сведения относятся только к своей музыке, не к внешнему каталогу.

## Сохранение

Локально сохраняются сигналы, лайки/дизлайки, история, ручная/автоматическая очередь, позиция, последовательность Previous и настройки Wave/Mix. Таблица trackCuePoints сохраняет и восстанавливает метки при подготовке/запуске. Сброс предпочтений и очистка истории доступны отдельно. Восстановленный сеанс ждёт действия пользователя для звука.
