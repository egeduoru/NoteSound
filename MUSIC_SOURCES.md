# Музыкальные источники NoteSound 2.0

| Источник | Реальное состояние |
|---|---|
| NoteSound Original | Восемь собственных CC0-инструменталов; поиск, аудио, Волна, Mix |
| Личные файлы | Локальный пользовательский импорт, не общий каталог |
| LicensedAudioProvider | Серверный реестр подтверждённых записей, поставляется пустым |
| HitmozProvider | Контракт JSON, поиск/чарты/детали и раздельная проверка аудио; оба флага выключены |
| LightAudio | Поиск и полные публичные потоки источника через отдельный discovery API; ДИНАСТИЯ 2:30 проверена в браузере |
| Deezer | Поиск метаданных и официальные 30-секундные фрагменты; каждый Play обновляет временную ссылку |
| YouTube | Внешний переход; официальный встроенный режим только под временным флагом отката |
| VK | Внешняя ссылка; полный встроенный аудиокаталог не заявлен |

## Права и доступность

Наличие названия, обложки или файла не означает лицензию на хранение, изменение или распространение записи. Публичное воспроизведение, предоставленное подключённым источником, отмечается отдельно (`streamAccess`), без присвоения подтверждённых авторских прав. Для LightAudio и Deezer Mix и скачивание выключены; отклонённые и metadata/внешние записи не включаются в аудиоочередь. JSON-импорт не может выдать себе права, доступ к потоку или доверенный произвольный audio URL.

Собственный каталог имеет канонические данные и лицензию в `public/audio/LICENSE.txt`. Личные файлы остаются локальными. Внешний каталог требует серверного реестра с доказательством прав, стабильным ID и публичным HTTPS-хостом из allowlist. Аудио проверяется HEAD; Mix дополнительно требует разрешения на сведение и рабочего CORS.

## Hitmoz

Исследован сторонний [Hitmoz Parser](https://github.com/Shukurov777/hitmoz-parser), не официальный API сервиса. Его контракт success/songs нормализуется на сервере, UI не зависит от HTML сайта. При проверке исходные домены вернули 403; разрешённый доступ и права на записи не подтверждены. Автоматического скачивания коммерческих MP3, обхода защиты и использования download как разрешённого потока нет. Подробности — [отчёт](docs/HITMOZ_2_REPORT.md).

## Поиск и рекомендации

Поиск принимает русский/английский запрос, применяет debounce, лимит длины, кеш и дедупликацию, переживает отказ отдельного адаптера. Discovery API задаётся VITE_DISCOVERY_API_URL; в локальном dev он автоматически направлен на порт 3002. VITE_MUSIC_API_URL относится к прежнему реестру лицензированных записей/Hitmoz. Ненайденная песня не заменяется собственной мелодией под чужим именем. Дубли коротких/полных записей сопоставляются с длительностью из Deezer; полные потоки приоритетнее preview. Фрагменты не включаются в Волну.

BPM, жанры, настроение, припевы и связи исполнителей из Hitmoz не предполагаются. Используются реальные метаданные, собственные размеченные записи и действия слушателя. Активных Last.fm/ListenBrainz/MusicBrainz-рекомендаций и полного каталога русских хитов в поставке нет. Другой лицензированный источник подключается через MusicProvider.
