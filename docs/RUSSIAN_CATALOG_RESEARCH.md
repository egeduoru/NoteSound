## Технические требования к интеграции

- [IFrame Player API](https://developers.google.com/youtube/iframe_api_reference) не требует YouTube Data API key для воспроизведения известного ID. Он поддерживает play/pause, seek, громкость, длительность, состояние и событие завершения.
- [Требования к встроенному плееру](https://developers.google.com/youtube/terms/required-minimum-functionality) требуют видимый плеер размером минимум **200×200 пикселей**, сохранение фирменных контролов/рекламы, отсутствие перекрывающих слоёв. Для запуска по сценарию autoplay более половины плеера должно быть видно на экране.
- Плеер нельзя делать невидимым аудиодвижком. Политики платформы не допускают извлечение аудиодорожки и фоновое воспроизведение вне видимого плеера.
- Нужно передавать `origin=location.origin` и сохранять реальный `HTTP Referer`: для iframe использовать `referrerPolicy="strict-origin-when-cross-origin"`. Подавленный Referer в WebView может приводить к ошибке 153. Это не обход защиты: при отказе плеер должен показать ошибку или официальный переход на страницу источника.
- Видео не загружается в IndexedDB, не скачивается как MP3 и не смешивается со звуком другого плеера. При переходе на обычный аудиотрек iframe должен останавливаться.
- Поиск по такому каталогу может выполняться локально по подтверждённым метаданным. Это подборка реальных записей, **не** неограниченный поиск по всему YouTube: официальный YouTube Data API search требует отдельного ключа/квоты.

## SoundCloud

Рассмотрены результаты для «ДИНАСТИЯ» и «8 миля». Большая часть результатов точного названия «ДИНАСТИЯ» в выдаче — станции или пользовательские перезаливы (`wx`, `SOURCE MUSIC`, `new music every friday`). Их нельзя автоматически считать официальными публикациями артистов. Есть [8 миля на madk1dmus](https://soundcloud.com/madk1dmus/8-milya), но совпадение имени профиля с артистом без перекрёстного подтверждения недостаточно для утверждения, что это официальный аудиокаталог.

SoundCloud поддерживает официальный виджет, но подтверждённый официальный источник конкретной «ДИНАСТИИ» в рамках проверки не установлен. Поэтому проверенная подборка YouTube предпочтительнее непроверенных SoundCloud-перезаливов. Извлекать временные MP3-потоки из виджетов не требуется.

## Ограничение проверки

HTTP 200/oEmbed/`playableInEmbed` подтверждают текущие метаданные и разрешённое встраивание, а не гарантированную работоспособность любого устройства или региона. Фактический запуск iframe и события плеера следует проверить в обычном браузере, затем на реальных iOS/Android внутри Telegram. Обход региональных ограничений, авторизации, DRM или блокировок не рассматривается.
