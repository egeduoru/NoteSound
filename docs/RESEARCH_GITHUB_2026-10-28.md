# GitHub: парсеры и клиенты для NoteSound

Проверено 28 октября 2026 года. Цель — бесплатный NoteSound для владельца и друзей, с русскими полными треками, без рекламы и монетизации.

Исследованы 12 реальных публичных репозиториев. Для каждого прочитаны метаданные GitHub API и README; для нескольких — ключевые файлы реализации. Сторонний код не устанавливался и не запускался, авторизация не выполнялась, музыкальные файлы не скачивались. Наличие функции в README означает заявление автора, а не доказанный успешный поиск/поток «ДИНАСТИИ» сейчас.

`pushed_at` ниже — дата последнего push по GitHub API, а не гарантия работоспособности или дата последнего исправления аудио. Даже свежий push может относиться к документации/переводу. У всех 12 репозиториев на момент проверки `archived=false`.

## Что выяснилось при чтении кода

### JadeMusic: папка адаптера не доказывает поддержку отдельного сайта

В [hitmo/data.py](https://github.com/nshib00/jademusic-api/blob/main/jademusic/audioparser/hitmo/data.py) описаны поиск, топ, новые треки, альбомы и подборки. Домен выбирается вспомогательным кодом. Это API-обёртка над сайтом, а не собственная база аудио.

В [mp3party/data.py](https://github.com/nshib00/jademusic-api/blob/main/jademusic/audioparser/mp3party/data.py) реально указан `mp3party.net`.

Но [youloud/data.py](https://github.com/nshib00/jademusic-api/blob/main/jademusic/audioparser/youloud/data.py) также задаёт `mp3party.net`, несмотря на имя YouLoud. Поэтому нельзя объявлять проект поддерживающим три независимых работающих каталога только по структуре папок. Это может быть незавершённый/скопированный адаптер; его живое поведение не проверено.

### VK SDK: аудиомодуль является веб-клиентом

В [vk_api/audio.py](https://github.com/python273/vk_api/blob/master/vk_api/audio.py) сам комментарий VkAudio описывает получение аудио без официального API. Код использует пользовательскую веб-сессию и HTML/web endpoints. Общий SDK пригоден для многих обычных VK-задач, но это не подтверждение, что VK официально выдаёт сторонним Mini App полный бесплатный музыкальный каталог.

### Meridius: бесплатная программа с закрытым исходным кодом

[README](https://github.com/PurpleHorrorRus/Meridius) указывает бесплатность и отсутствие коммерческих целей, но одновременно описывает программу как проприетарную. [FAQ](https://github.com/PurpleHorrorRus/Meridius/blob/master/manual/faq/ru.md) прямо говорит, что исходники пока не опубликованы, и описывает парольный вход. Значит, считать этот GitHub открытой реализацией музыкального API нельзя. Связаться с автором о документированном интерфейсе можно отдельно, но сообщений в рамках этой проверки не отправляли.

### Yandex: актуальная библиотека не означает бесплатный доступ к полным файлам

[README yandex-music-api](https://github.com/MarshalX/yandex-music-api) чётко отделяет работу без входа от авторизованной. Ограничение 30 секунд особенно важно: наличие поиска «ДИНАСТИЯ» или ссылки в ответе ещё не подтверждает полноценное свободное воспроизведение. В репозитории есть радио/очередь и работа с файлами, но доступ конкретного пользователя и разрешение интеграции остаются вопросами сервиса. Токены не получались и не запрашивались.

### Spotify в названиях GitHub часто означает только метаданные

[spotDL README](https://github.com/spotDL/spotify-downloader) прямо разделяет Spotify-метаданные и YouTube-аудио. А присланный Eevee-проект — iOS-модификация клиентского приложения. Ни один из этих проектов не является независимым музыкальным поставщиком для NoteSound с полными оригинальными аудиофайлами Spotify.

## Что стоит использовать в дальнейшем

1. **Для собственной коллекции:** схема загрузки файлов через Telegram и Navidrome. Можно сохранить интерфейс NoteSound, подключив закрытый сервер через документированный API. Источник и разрешения на каждую запись остаются понятными. Пример uploader полезнее случайного старого MP3-скрапера.
2. **Для готового внешнего каталога:** сначала искать поставщика с документированным API и условиями воспроизведения. Открытый исходник парсера даёт технику разбора, но не заменяет работоспособный каталог и права на записи.
3. **Для исследования похожих интерфейсов:** Meridius и yandex-music-api показывают, что личные бесплатные клиенты существуют; при этом сессии, подписки, закрытый код и условия upstream нельзя считать исчезнувшими.
4. **Не тратить время на замену одного старого Hitmo-парсера другим без нового подтверждения:** NDRAEY и JadeMusic значительно старше текущего HTML. Их наличие на GitHub не исправляет 403 и не подтверждает возможность встраивания.

Среди этих 12 репозиториев не подтверждён готовый бесплатный независимый API полных русских хитов, который можно включить в NoteSound без аккаунтов/условий внешнего сервиса. Это вывод о проверенной выборке, а не утверждение, что такого решения нигде не существует.
