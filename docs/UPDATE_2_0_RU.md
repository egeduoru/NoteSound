# Как обновить существующий NoteSound до 2.0

Готовый архив: `outputs/NoteSound_2_0_source.zip`. Он содержит исходники, примеры настроек и документацию. Папка с уже распакованными файлами: `outputs/NoteSound_2_0_upload`.

## Проверка на этом компьютере

Откройте `http://127.0.0.1:5173/`. На главной раскройте «Оригинальные тестовые записи NoteSound» и запустите песню. Нажмите на нижнюю полоску плеера: откроется обложка и музыкальное управление. Очередь подбирается автоматически.

Для проверки сведения откройте настройки и включите Wave Mix. Он отдельно от Волны; стандартно выключен. Тестовые записи короткие, поэтому переход можно дождаться без перемотки. «Моя музыка» позволяет добавить собственный аудиофайл.

## Обновление GitHub Pages

1. Сохраните текущий репозиторий/его историю. Личную библиотеку при необходимости экспортируйте через настройки приложения.
2. Откройте существующий репозиторий `egeduoru/NoteSound` → **Add file → Upload files**.
3. Из папки `NoteSound_2_0_upload` загрузите сначала все файлы и папки **кроме `public` и `docs`**. Загружайте содержимое прямо в корень репозитория; папка `NoteSound_2_0_upload` не должна стать вложенной папкой сайта. Сохраните через **Commit changes**.
4. Второй загрузкой добавьте папки `public` и `docs` в корень и сохраните изменения.
5. Проверьте, что обновился `.github/workflows/deploy.yml`. В нём основной режим YouTube выключен. Если папка `.github` не попала через Upload, откройте существующий workflow на GitHub и замените его текст содержимым файла из архива.
6. В **Settings → Pages** оставьте **GitHub Actions**. Во вкладке **Actions** дождитесь зелёных `build` и `deploy` последнего запуска.
7. Откройте `https://egeduoru.github.io/NoteSound/`, полностью закройте и снова откройте Mini App в Telegram. В настройках должна быть версия **2.0.0**.

BotFather и адрес бота менять не нужно. Новый YouTube API key для этой версии не требуется.

## Каталог русских хитов

Эта загрузка обновит плеер и Волну. Полный внешний каталог автоматически не появится. Сейчас доступны собственные записи NoteSound и личные файлы.

Для внешнего каталога нужен отдельный сервер Node с HTTPS, разрешённый поставщик музыки/Parser API и заполненный реестр разрешённых записей. Порядок настройки — в [DEPLOYMENT.md](../DEPLOYMENT.md). Hitmoz по умолчанию выключен: доступ и права воспроизведения не подтверждены, ранее сайт отвечал HTTP 403.

`BOT_TOKEN`, `server/.env`, `.env.local` и реальный приватный реестр в GitHub загружать не нужно. В архиве находятся только безопасные примеры.

Фоновый звук использует возможности браузера, но продолжение при сворачивании Telegram на iPhone пока не подтверждено: это нужно отдельно проверить на устройстве.
