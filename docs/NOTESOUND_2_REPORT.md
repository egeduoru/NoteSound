# NoteSoundbot 2.0 — итоговый технический отчёт

Дата: 28 октября 2026 года. Основа — существующий NoteSoundbot, проект MusicTG. Версия 2.0 подготовлена локально; сайт обновится после загрузки исходников и успешного workflow. Бот и адрес Mini App сохранены.

## 1. Изменённые файлы

Полный перечень отличий от архива до 2.0: [CHANGED_FILES_2_0.md](CHANGED_FILES_2_0.md). Основные группы: типы/адаптеры, аудио/транспорт, wave/taste/mix, store/IndexedDB, плеер/поиск/настройки/стили, новый server, конфигурация и тесты. Описание — [CHANGES_RU.md](../CHANGES_RU.md).

Откат: outputs/rollback/NoteSound_before_2_0_2026-10-28.zip, рядом контрольная сумма. Без секретов, зависимостей и локальных проверочных файлов.

## 2. Архитектура

UI → Zustand → MusicProvider → собственный/личный каталог либо отдельный Node API. Один PlaybackController управляет AudioEngine. Smart Wave строит очередь; независимый Wave Mix сводит совместимые деки. Media Session отражает текущий трек. Библиотека/сеанс/вкусы в Dexie v4. Карта — [ARCHITECTURE.md](../ARCHITECTURE.md).

История и сеанс используют существующие store/storage; пустые классы ради названий ТЗ не добавлены. YouTube сохранён только как выключенный откат.

## 3. Запуск

Node.js 24, pnpm 11.25.0: pnpm install --frozen-lockfile, затем pnpm dev. Для CC0/личного аудио внешние ключи не нужны. Production: pnpm build, pnpm preview. API: node --env-file=server/.env server/index.mjs после копирования примера. Подробно — [DEPLOYMENT.md](../DEPLOYMENT.md).

## 4. Окружение

Frontend: VITE_BASE_PATH, VITE_MUSIC_API_URL, выключенный VITE_LEGACY_YOUTUBE_ENABLED; старый YouTube-ключ только для отката. Backend: HOST/PORT, APP_ORIGINS, серверный BOT_TOKEN, REQUIRE_TELEGRAM_AUTH, срок сеанса, отдельные флаги Hitmoz, Parser URL/allowlist, реестр/allowlist аудио. BOT_TOKEN не входит в VITE.

Pages остаётся статическим frontend; Node API публикуется отдельно. Workflow обновлён, BotFather повторно настраивать не нужно.

## 5. Проверки

Финальный общий прогон: **324 теста, 22 файла, все пройдены**. Проверка типов, lint и production-сборка пройдены. В браузере 390×844 подтверждены аудио с обложкой, автоматическое продолжение, очередь из семи записей с причинами и смена обложек в переходе с запуском следующей записи по метке. Подробности и подтверждения — [VERIFICATION.md](../VERIFICATION.md).

Тесты покрывают границу парсера, права, SSRF, Telegram-сеансы, аудиособытия/гонки, Wave/очередь/сигналы, Mix/Cue и миграции. Подставные сеть/AudioContext/Bot API не доказывают live-каталог, отправку музыки или фон iPhone. Физические iPhone/Android здесь не проверены.

## 6. Реальная интеграция Hitmoz

Provider и Node-граница принимают документированный success/songs, поддерживают устойчивые ID, поиск/топ/детали, кеш и отдельное разрешение аудио. download не даёт права воспроизведения. Исходные домены вернули 403; live-поиск/MP3 не подтверждены. Оба флага выключены. [Отчёт](HITMOZ_2_REPORT.md).

## 7. Остающиеся разрешения

Нужны условия доступа к метаданным и права на воспроизведение конкретных записей, отдельно на Mix/доставку. Затем собственный Parser API либо лицензированный поставщик, реестр, HTTPS-файлы и CORS. Полный коммерческий каталог русских хитов не включён; технические флаги права не заменяют.

## 8. Smart Wave

Автозапуск после выбора аудио, перестройка по новому треку, целевые 40/30/20/10, взвешенная случайность и тестовый seeded RNG. Лайк +5, избранное +4, фактическое слушание 70% +2, повтор +2, ранний skip −1, dislike −8 с исключением. Веса/настройки сохраняются.

Цель семь следующих записей, пополнение ниже трёх, ручные первыми. Текущий трек/очередь/дизлайки исключаются; 30 дней и разнообразие ослабляются при нехватке каталога. Previous — фактическая последовательность. Бюджет операций ограничен. [Описание](../WAVE_ENGINE.md).

## 9. Wave Mix

Независимый модуль, стандартно выключен: общий AudioContext, максимум два канала, cosine/sine equal-power fade, запас −3 dB, 2–12 секунд, стандарт 6. Подготовка, Pause/Resume двух дек, отмена при Next/ручном выборе/seek, защита от устаревших операций и освобождение ресурсов. Согласованы обложки и Media Session.

Нужны права и same-origin/blob/CORS. Достоверные Cue In/Out либо начало 0:00 и fade у конца. Свой каталог размечен по авторским тактам, не распознанным припевам. Ошибка Mix не должна лишать обычное аудио самостоятельности.

## 10. Ограничения

- Hitmoz playback и полный каталог русских хитов не включены без доступа/прав.
- Telegram/ОС могут остановить фон; Media Session не гарантирует Mix в замороженном WebView.
- Локальная библиотека без облачной синхронизации; JSON не переносит аудиобайты.
- Нет автоматического распознавания припевов, beat matching/time stretching и внешней рекомендательной базы.
- sendLicensedAudio — выключенная отдельная функция без маршрута/кнопки; Bot API-сообщение реально не отправлялось.
- Node API/новая сборка требуют публикации; Docker/хостинг/физические устройства отдельно не проверены.
