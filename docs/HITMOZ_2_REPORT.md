# Hitmoz: результат интеграции NoteSound 2.0

Дата: 28 октября 2026 года.

## Что исследовано

Проверены [репозиторий](https://github.com/Shukurov777/hitmoz-parser), [README](https://github.com/Shukurov777/hitmoz-parser/blob/main/README.md), [Python-парсер](https://github.com/Shukurov777/hitmoz-parser/blob/main/parser.py) и [PHP-обёртка](https://github.com/Shukurov777/hitmoz-parser/blob/main/index.php). Это сторонний парсер, не официальный API. Python обрабатывает HTML, PHP предоставляет HTTP-обёртку.

Операции — ?search=<query> и ?top-today. Ответ содержит success, mode, query при поиске, source, count, songs. У записи: rank, title, artist, duration, cover, download, link. MIT-лицензия кода не даёт прав на музыку; README относит права контента к правообладателям и сайту.

При прямой проверке eu.hitmoz.com и ru.hitmoz.org получен HTTP 403. Это результат из проверявшей среды, не доказательство недоступности для всех. Обход не выполнялся; live-поиск конкретной песни и воспроизведение её MP3 не подтверждены.

## Что реализовано

- Frontend Provider работает через наш Node API: поиск, топ, детали, отдельное разрешение аудио.
- server/catalog-model.mjs проверяет контракт, очищает поля, переводит время в секунды, удаляет дубли и создаёт устойчивый ID по странице либо исполнителю/названию.
- download не переносится в разрешённый поток. Без канонического реестра запись остаётся metadata с неизвестными правами.
- Фиксированный HTTPS Parser URL, точный allowlist, DNS/SSRF-проверки, кеш, таймауты, ограничения параллельности/запросов и корректные ошибки.
- Аудио только по подтверждённой записи реестра и допустимому хосту, после HEAD; для Hitmoz дополнительно нужен playback-флаг.
- Оба флага Hitmoz пока выключены; остальные функции работают на собственном аудио.

## Что проверяют тесты

Документированный формат, кириллица, пустой/изменённый JSON, стабильные ID, дубли, недоверенные URL, права и default-off проверяются с локальными ответами. Итоговые числа — [VERIFICATION.md](../VERIFICATION.md). Ответы тестов не выдаются за live-доступ.

## Что нужно для включения

1. Условия разрешённого автоматического доступа к метаданным и их использования в приложении.
2. Законный рабочий доступ собственного Parser API без обхода 403/защиты/авторизации.
3. Подтверждённые права NoteSound воспроизводить каждую запись на нужных территориях.
4. Отдельные права сведения и доставки в Telegram для соответствующих функций.
5. Доступные HTTPS-аудиоадреса, HEAD/MIME, CORS для Mix и точные allowlist.

После этого владелец наполняет реестр, настраивает [окружение](../DEPLOYMENT.md), публикует API и проверяет реальные записи. В текущей поставке нет обещания русских хитов или «ДИНАСТИИ» во встроенном аудиорежиме.
