# NoteSound — светлый Liquid Glass

Интерфейс полностью переведён на новую светло-фиолетовую тему. Основная навигация содержит ровно три вкладки: «Моя Волна», «Поиск», «Моя музыка». Корневой адрес открывает Волну. Настройки доступны через шестерёнку, без отдельной вкладки.

Новая тема реализована в src/styles/liquid-glass.css: три постоянно движущихся цветовых слоя, стеклянные панели с blur/saturation и световыми кромками, плавающая навигация, стеклянный мини-плеер и полноэкранный плеер. Фоновое видео и новые графические зависимости не используются. Системное сокращение движения и настройка reducedMotion отключают анимацию.

Переработаны Волна, Поиск и библиотека, сохранены аудиопотоки, очереди, избранное, история, импорт и плейлисты. Прежняя тёмная тема больше не импортируется. Цвета Telegram, HTML theme-color и PWA manifest согласованы со светлым фоном.

Проверки:

- 385 тестов прошли; TypeScript и ESLint без ошибок; production-сборка успешна.
- В браузере проверены ровно три главных пункта навигации, их переключение, поиск ДИНАСТИИ (первый результат, 2:30), фильтры библиотеки, открытие/закрытие диалога плейлиста и полноэкранный плеер.
- Нет горизонтального переполнения на проверенном узком экране. У навигации фактический backdrop-filter blur(32px) saturate(1.75). Все три фоновых слоя имеют запущенную анимацию.
- Исправлены переход к основному содержимому при HashRouter и видимый фокус поля направления Волны.

Локальная версия: http://127.0.0.1:5173/#/wave

## Типографика по референсам пользователя

Manrope и системный шрифт заменены на локальный Golos Text (400–900), источник — официальный каталог Google Fonts. Открытая лицензия включена в public/fonts/OFL-Golos-Text.txt. «Моя волна» использует вес 800, строчную «в» и межбуквенное расстояние −0.02em вместо прежнего −0.065em. Остальные заголовки стали плотнее, обычный текст — 400, названия песен — 550. Это приближение характера референсов, а не оригинальный шрифт Яндекса.

Шрифт проверен через document.fonts в браузере и включён в офлайн-оболочку. TypeScript, ESLint и сборка прошли; горизонтальное переполнение не появилось. Скриншот: notesound-typography-2026-10-28.png.

Сайт GitHub Pages и Telegram этой локальной правкой автоматически не публикуются. Для обновления применяются существующие настройки сервера и workflow; новый архив содержит весь исходный проект.
