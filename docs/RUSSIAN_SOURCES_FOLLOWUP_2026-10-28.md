## Новый подход для закрытого круга

Navidrome хранит собственную музыкальную коллекцию и отдаёт её через Subsonic/OpenSubsonic API. Его можно поставить на имеющийся Windows/Linux-компьютер и использовать NoteSound как отдельный клиент. Программа бесплатная, поддерживает учётные записи, поиск, метаданные, обложки и потоковое воспроизведение.

Возможная схема: личные разрешённые файлы → папка коллекции → Navidrome → защищённый API → NoteSound. Добавление файлов через Telegram можно реализовать отдельно с ограниченным списком пользователей. Авторизация и права доступа должны проверяться сервером, токены не должны попадать в публичную сборку.

Это способ организовать уже имеющуюся коллекцию, а не получить весь каталог хитов автоматически. Если использовать свой компьютер, он должен быть включён во время прослушивания. Для внешнего доступа нужен HTTPS и выбранный способ защищённого подключения; нулевую стоимость облачного хостинга/хранения навсегда обещать нельзя. Бесплатный Render с исчезающей файловой системой не подходит как постоянное хранилище коллекции.

Для открытого независимого каталога Jamendo реалистичнее случайного MP3-парсера: условия прямо описывают некоммерческое использование. Но чужой каталог нельзя выдавать за наличие MACAN/madk1d. Офлайн-кэш и права на Mix требуют отдельной проверки: Jamendo API ограничивает офлайн-приложения, лицензии различаются.
