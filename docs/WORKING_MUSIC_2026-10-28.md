# Работающий поиск и аудио NoteSound — 28 октября 2026

## Что реализовано

Вместо неработающего JadeMusic подключены два независимых discovery-адаптера. LightAudio даёт метаданные и публично предлагаемый источником MP3-поток; Deezer — метаданные и отдельно обозначенные фрагменты до 30 секунд. Воспроизведение использует обложку и обычный HTMLAudio, без видеоплеера YouTube. Полные потоки участвуют в Волне. Скачивание и Mix для новых источников не включены; авторские права на внешние записи не объявляются подтверждёнными.

Сервер получает только страницы/JSON с фиксированных хостов, ограничивает время и объём ответа, не следует редиректам и не обходит HTTP 403. Аудио браузер получает непосредственно от источника; сервер не хранит песни. Детали обновляются при запуске; сохранённый LightAudio-трек восстанавливается поиском точного ID после перезапуска сервера.

## Локальный запуск

Два терминала в папке проекта:

```powershell
npm run dev:catalog
npm run dev
```

Приложение: http://127.0.0.1:5173/

Discovery API: http://127.0.0.1:3002/

JadeMusic на порту 8001 для поиска больше не нужен. Публичный сайт и Telegram пока автоматически не обновлялись.

## Публикация в существующий проект

1. Загрузить изменённые файлы в GitHub с сохранением путей. Архив обновления содержит папку `upload` с ними.
2. Создать Web Service для Node API на Render Free из того же GitHub-репозитория: Language — Node, Root Directory — пусто, Build Command — `node --version`, Start Command — `node server/index.mjs`. Переменная HOST должна быть `0.0.0.0`; APP_ORIGINS — `https://egeduoru.github.io,http://127.0.0.1:5173`. Выбрать Free и проверить стоимость $0 перед запуском. Секреты для этих двух источников не нужны. Альтернатива — новый сервис по приложенному render.yaml с Docker.
3. В GitHub Settings → Secrets and variables → Actions → Variables установить `VITE_DISCOVERY_API_URL` равной реальному HTTPS-адресу Render. Затем запустить workflow Build and deploy NoteSound. Файл workflow уже передаёт эту переменную в сборку.

Публичный Render должен отдельно пройти проверку `/api/discovery/public/search?q=MACAN`: его сеть может иметь другую доступность источников. На Free после простоя бывает холодный запуск. Условия внешних сервисов и их доступность могут меняться; локальная проверка не подтверждает будущую доступность из Render.
