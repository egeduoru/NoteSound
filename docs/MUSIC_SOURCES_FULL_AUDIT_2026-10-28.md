# Расширенный аудит музыкальных источников NoteSound

Проверено 28 октября 2026 года. Сценарий: бесплатное приложение для себя и друзей, без рекламы и монетизации; нужны современные русские песни, собственный плеер с обложками, автоматическая Волна и необязательный Mix.

## Итог

Проверены 13 веб-источников, 10 официальных API/SDK, 12 GitHub-проектов и 7 моделей собственной библиотеки. Категории пересекаются: парсер и сайт, из которого он берёт музыку, не являются двумя независимыми каталогами. Это расширенная проверка перечисленных вариантов, а не заявление об исследовании каждого сайта в интернете.

Подтверждены доступные страницы нужной записи у нескольких сайтов, действующие официальные API для отдельных каталогов и осуществимая архитектура личного сервера. Не подтверждён бесплатный готовый поставщик, который одновременно обеспечивает всю нужную русскую дискографию, разрешает собственный HTMLAudio-плеер, Mix и хранение без дополнительных условий.

Наиболее содержательные кандидаты:

1. **Musify** — запись «ДИНАСТИЯ» найдена; условия прямо описывают встраивание собственного плеера сайта. Но это отдельный режим с ограничениями сервиса, не разрешение автоматически копировать MP3 в NoteSound. В проверенном JS нет внешнего postMessage-управления; бесшовная Волна пока не подтверждена.
2. **LightAudio** — реальный поиск «ДИНАСТИЯ madk1d» ответил HTTP 200 и вернул варианты, включая указание 2:30. Есть правовая информация и контакт технической поддержки. Условия API для чужого проигрывателя и права на Mix не подтверждены; это следующий кандидат для согласования, а не уже подключённый источник.
3. **MUZ-TOP / Muzend / Muzjoy** — точные карточки открываются; автоматическое получение аудио и условия подключения не подтверждены. MUZ-TOP сообщает, что использует сторонние источники.
4. **Navidrome + NoteSound** — наиболее управляемая модель своей коллекции. Даёт полноценное аудио из добавленных файлов и собственный интерфейс, но не наполняет библиотеку хитами автоматически.
5. **Jamendo / выборочные Audius** — документированный доступ к отдельной музыке; наличие требуемого коммерческого репертуара не подтверждено.

## Как проверяли

Сопоставлены README, реальный код отдельных проектов, официальные условия и документация. Сделаны ограниченные прямые GET публичных страниц и поисковых API. Отключены автоматические переходы при сетевых проверках: один обычный переход LightAudio и Rilds разобран отдельно по полученному Location. Ошибки 403/451 не обходились.

Проверены метаданные, длительности, формы поиска, ссылки на условия, HTTP-заголовки CORS/iframe и наличие внешнего интерфейса управления. Само наличие MP3-ссылки в HTML не засчитывается как разрешённый рабочий поток.

Аудиофайлы не скачивались, чужой код не запускался, аккаунты/токены/подписки не использовались, новые провайдеры в приложение не включались. Браузерная попытка проверить Musify не завершилась, поэтому реальное воспроизведение/iframe в Telegram и фон на iPhone не объявляются проверенными. Прямые сетевые результаты относятся к этой среде, кроме ранее полученного пользователем 403 на Render.

### Musify: что именно найдено

[Пункт 5.1 условий](https://musify.club/en/contacts/terms) разрешает отображение через плеер сайта в embed/iframe. Пункт 4 описывает ограничения бесплатного режима и Premium. Это перспективный режим аудиоисточника с его собственными контролами, без YouTube-видео, при сохранении ограничений сервиса.

В прочитанном публичном файле `main.CDlhgbgN.js` (около 300 КБ) есть маршрут `/api/track/{id}/stream-url`, но нет вхождений `postMessage`. Это недостаточно для утверждения об отсутствии любого API: не найден документированный внешний контракт управления. Внутренний маршрут сайта нельзя выдавать за поддерживаемый API NoteSound.

Для интеграции нужны точный поддерживаемый embed URL, допустимые параметры и события play/pause/ended/seek либо разрешённый аудио API. Иначе NoteSound не сможет достоверно синхронизировать очередь/прогресс, а Wave Mix между закрытыми iframe не работает как между HTMLAudio-деками.

[Правовая информация Musify](https://musify.club/contacts/legal) описывает разрешения, предоставленные именно сайту. Это не самостоятельная лицензия любому внешнему приложению на распространение всех файлов.

### LightAudio: что изменилось после предыдущего отчёта

Нужная запись теперь найдена **реальным поисковым запросом** из текущей среды: [поиск ДИНАСТИЯ madk1d](https://web.ligaudio.ru/?mp3=%D0%94%D0%98%D0%9D%D0%90%D0%A1%D0%A2%D0%98%D0%AF+madk1d). Ответ 200, на странице заявлена 191 композиция; это число всех вариантов поиска, не 191 подтверждённый оригинал. Есть версии разной длительности, именования и загрузчики.

[Правовая информация](https://web.ligaudio.ru/?info=legalnotice) заявляет бесплатность для конечного слушателя и соглашение сайта с АдвМьюзик для некоторых произведений. Внешнее API/перенос этих разрешений на NoteSound в прочитанном тексте не описаны. Контакты сайта: mail@lightaudio.ru; по указанным правообладателям — support@advmusic.com. Писем не отправляли.

## Официальные API: 10 вариантов

Подробности: [RESEARCH_OFFICIAL_APIS_2026-10-28.md](RESEARCH_OFFICIAL_APIS_2026-10-28.md).

- **Jamendo:** наиболее ясные условия бесплатного некоммерческого API; нужны свой ключ приложения, атрибуция, соблюдение лицензии записи и ограничений офлайн-кэша. Требуемый хит не подтверждён.
- **Audius:** бесплатное чтение/stream доступных записей, но реальный поиск ДИНАСТИЯ дал 0. Пользовательские загрузки MACAN/Miyagi не равны официальной дискографии.
- **Deezer:** реальный API-поиск нашёл ДИНАСТИЮ (150 секунд) с preview. Это полезно для метаданных, не доказательство получения полной песни.
- **SoundCloud:** для регистрации API требуется Artist Pro; есть дополнительные ограничения агрегаторов и хранения. Бесплатность прослушивания сайта не равна бесплатному SDK для нашего сценария.
- **Spotify / Apple Music:** полное SDK-прослушивание связано с подпиской и условиями пользователя. Это отдельный платный режим, не бесплатная общая аудиобиблиотека.
- **Яндекс / VK / Звук:** в проверенных официальных источниках не подтверждён свободный полный API для нового внешнего плеера. Неофициальные токены/веб-сессии не считаются независимым источником.
- **YouTube:** поиск и официальный видеоплеер не дают отдельное аудио для HTMLAudio/Mix; скрытое видео не соответствует выбранной архитектуре.

### Дополнительные каталоги и API

- **[ccMixter](https://ccmixter.org/query-api):** найден документированный Query API и [явное разрешение для сторонних сайтов/приложений](https://ccmixter.org/about/attributionGenerator). Реальный GET `api/query?f=json&search=russian&search_type=any&limit=5` дал 200 и пять записей с license_url, включая CC BY и CC BY-NC. Поиск по слову russian может совпадать с описанием: русский вокал и нужные хиты этим не подтверждены. Это полезная новая основа независимого каталога, но не замена дискографии madk1d. Потоки не скачивались.
- **[Free Music Archive](https://freemusicarchive.org/FAQ):** FAQ и [условия](https://freemusicarchive.org/terms_of_use) описывают лицензии на уровне конкретной записи, фильтры и необходимость отдельного согласия при смешивании NoDerivatives. Самостоятельный актуальный full-catalog API и нужная запись в исследовании не подтверждены.
- **[Internet Archive](https://archive.org/developers/metadata.html):** есть публичное чтение метаданных. [Справка о правах](https://help.archive.org/help/rights/) прямо не гарантирует правовой статус пользовательских загрузок. Архив нельзя считать автоматически лицензированным поставщиком всех найденных песен. Живой поиск целевого хита здесь не проводился.
- **[Bandcamp](https://bandcamp.com/developer):** официальный API предназначен для лейблов и партнёров обработки заказов, с OAuth и выдачей доступа. Это не открытое бесплатное full-stream API всего Bandcamp. Отдельные покупки/бесплатные релизы для своей коллекции — другой сценарий.

Эти четыре дополнительных направления не включены в исходные числа 13 веб-площадок и 10 основных API/SDK. Наличие API и наличие нужного русского репертуара проверяются раздельно.

## Собственная коллекция: 7 моделей

Подробности: [RESEARCH_PERSONAL_LIBRARY_2026-10-28.md](RESEARCH_PERSONAL_LIBRARY_2026-10-28.md).

Для существующего NoteSound лучший готовый сервер коллекции — Navidrome. Альтернативы: Jellyfin, Nextcloud Music, Ampache, личные файлы текущего браузера, загрузки через бота, файловая выдача из своего Node backend. Все требуют наполнения разрешёнными файлами и не предоставляют каталог хитов автоматически.

Navidrome на уже имеющемся Windows-компьютере позволяет обойтись без покупки серверного ПО; компьютер, сеть и диск должны работать. Для доступа извне нужны HTTPS и авторизация. У бесплатного Render записанные файлы исчезают при остановке/перезапуске — это не постоянное хранилище музыкальной коллекции.

Текущий Node API NoteSound реализует реестр/каталог и проверку источника, но не общий пользовательский upload, выдачу своих файлов и облачную медиатеку. Добавление нового источника не включит фоновую работу Telegram/iOS автоматически.

## Рекомендованное решение по целям

| Твоя главная цель | Приоритет | Следующий проверяемый результат |
|---|---|---|
| Готовые современные русские хиты без ручного наполнения | Согласованный Musify embed/API, затем LightAudio; MUZ-TOP/Muzend/Muzjoy — запасные кандидаты | Поддерживаемый контракт, условия, реальное воспроизведение и лимиты. Не достаточно увидеть карточку |
| Полностью свой плеер, Волна/Mix и закрытый круг друзей | Navidrome + provider в NoteSound | Один добавленный файл ищется и играет на двух устройствах с раздельной авторизацией |
| Бесплатный внешний каталог независимой музыки | Jamendo + выборочно проверенные Audius | Реальный разрешённый полноформатный трек, атрибуция, корректная обработка запрета Mix/скачивания |
| Точная ДИНАСТИЯ прямо сейчас без изменений приложения | Открытие у поддерживающего её источника | Условия и доступность источника остаются; это не собственный плеер NoteSound |

Для твоего исходного требования готового бесплатного каталога первым следует согласовать **Musify/LightAudio**, а не тратить время на ещё один старый Hitmo-парсер. Для независимости от чужих сайтов — **Navidrome с собственной коллекцией**. Бесплатность и отсутствие монетизации учтены; разрешённые некоммерческие интеграции существуют, но их репертуар и условия различаются.
