# Официальные музыкальные API для NoteSound — 28 октября 2026

Сценарий: бесплатное приложение для владельца и друзей, без монетизации, с полными русскими песнями, обложками и собственным плеером. Проверены первичные официальные страницы. Регистрация приложений, получение ключей, вход в чужие аккаунты, загрузка MP3 и публикация не выполнялись.

## Вывод

Среди проверенных официальных вариантов не подтверждён готовый бесплатный API, который одновременно даёт полный каталог современных русских хитов, собственный HTMLAudio-плеер NoteSound, разрешённый Wave Mix и офлайн-хранение. Это результат проверки перечисленных сервисов, а не доказательство отсутствия такого поставщика во всём интернете.

Практические направления: Jamendo для независимой музыки при соблюдении его условий; Audius для выборочных проверенных записей, но не как обещанная полная русская дискография; индивидуальное соглашение с поставщиком; собственная разрешённая коллекция. Платные подписочные SDK можно подключать отдельным режимом, если изменить требование о бесплатном прослушивании.

## Подтверждённые подробности

### Jamendo

Условия прямо разрешают некоммерческое API, но требуют соблюдать Creative Commons-лицензию конкретного контента, показывать автора/Jamendo и обратную ссылку. Условия ограничивают специально организованный офлайн-доступ и клонирование опыта Jamendo. Поле audiodownload_allowed отражает выбор артиста; оно не отменяет остальные API-условия. Подключение потребует лицензий/атрибуции в модели Track и отдельных флагов для Mix/скачивания.

Источники: [API terms](https://devportal.jamendo.com/api_terms_of_use), [метод tracks](https://developer.jamendo.com/v3.0/tracks), [портал](https://developer.jamendo.com/v3.0).

### Audius

Официальные документы действительно поддерживают поиск/поток, а тариф Free достаточно велик для тестового приложения друзей. Однако найденные названия MACAN/Miyagi не гарантируют официальную дискографию: результаты содержат другой uploader и иногда all-rights-reserved/null лицензию. Для текущей задачи нужен отбор, а не автоматический допуск всех результатов. Подробности живых проверок записаны в общем отчёте источников этой сессии.

Источники: [API](https://docs.audius.co/api/), [SDK и тариф](https://docs.audius.co/sdk/).

### SoundCloud

Помимо платного Artist Pro для получения учётных данных есть содержательное ограничение: API-условия не допускают альтернативный on-demand агрегатор нескольких загрузчиков или смесь SoundCloud с другими сервисами без специальной лицензии. Также нужны атрибуция и разрешение на изменения, а постоянные загрузки/офлайн запрещены. Виджет — отдельный официальный путь показа трека, а не автоматическое разрешение на собственный audio-only агрегатор.

Источники: [регистрация](https://developers.soundcloud.com/docs/api/register-app), [API terms](https://developers.soundcloud.com/docs/api/terms-of-use), [guide](https://developers.soundcloud.com/docs/api/guide).

### Spotify

В текущей официальной документации: Premium для слушателя Web Playback SDK; владелец development-приложения также должен иметь Premium; максимум пять авторизованных пользователей из allowlist. Условие приложения «для друзей» подходит по масштабу, но не отменяет подписки. Условия сохранения исходного контента не дают основания переносить треки в собственный Wave Mix. Готовый модифицированный клиент Spotify на GitHub не заменяет эти интерфейсы.

Источники: [SDK reference](https://developer.spotify.com/documentation/web-playback-sdk/reference), [quota modes](https://developer.spotify.com/documentation/web-api/concepts/quota-modes), [developer policy](https://developer.spotify.com/policy).

### Apple Music и Deezer

MusicKit — реальный официальный способ своего интерфейса над платной подпиской Apple Music. Нативная личная медиатека без подписки не превращается в бесплатный общий каталог. Стоимость Apple Developer Program в этой проверке отдельно не устанавливалась.

Deezer-поиск подтвердил нужную карточку и наличие preview. Продолжительность записи 150 секунд — метаданные полного трека, а не доказательство, что preview имеет эту длину. Проверка preview-файла или полного аудио не выполнялась. Новая регистрация Deezer developer app не подтверждена из первичной доступной страницы; сообщения сторонних библиотек о закрытии регистрации не используются как окончательное доказательство.

Источники: [MusicKit](https://developer.apple.com/musickit/), [Apple WWDC26](https://developer.apple.com/videos/play/wwdc2026/254/), [Deezer developer](https://developers.deezer.com/), [Deezer developer terms](https://cdn-content.dzcdn.net/pdf/CGU-developers.pdf), [публичный поиск Deezer](https://api.deezer.com/search?q=VILLIAN%20madk1d%20%D0%94%D0%98%D0%9D%D0%90%D0%A1%D0%A2%D0%98%D0%AF&limit=5).

### Российские подписочные сервисы

Не обнаружить API за отведённую проверку не означает доказать отсутствие партнёрских контрактов. Для Яндекс/VK/Звука честный статус — внешний бесплатный полный плеер для нового NoteSound не подтверждён. Нужен ответ команды платформы/партнёрства, а не подбор чужих токенов.

Источники: [Яндекс: условия](https://yandex.ru/legal/music_termsofuse/ru/), [Яндекс: поддержка](https://yandex.ru/support/music/ru/write-to-support), [VK: проверявшаяся audio API-страница](https://vk.com/dev/audio_api), [Звук: бесплатные функции](https://help.zvuk.com/article/48387), [Звук: условия](https://zvuk.com/terms), [Звук: подписка](https://zvuk.com/sub).

### YouTube

Для ранее запрошенной архитектуры с обложками скрытый видеоплеер не является подходящим решением. Нельзя считать поиск YouTube подтверждённым аудиокаталогом для HTMLAudio, offline и Wave Mix.

Источник: [YouTube API developer policies](https://developers.google.com/youtube/terms/developer-policies).

## Границы исследования

Документация и публичные metadata GET проверены 28 октября 2026. Закрытые API, личные музыкальные аккаунты, OAuth, подписки и географическая доступность физических устройств не тестировались. Ключи не извлекались, аудиофайлы не скачивались, ограничения не обходились. Отсутствие совпадения в одном запросе не доказывает отсутствие песни во всём каталоге. Нет гарантии доступности конкретного трека в регионе каждого друга.
